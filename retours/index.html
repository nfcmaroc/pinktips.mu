Retours et échanges

Chaque set Pink Tips est fait main. Pour des raisons d'hygiène, nous acceptons les retours uniquement pour les produits défectueux. Nous n'acceptons pas les échanges.

Produit défectueux

Si votre set arrive abîmé, cassé ou non conforme, écrivez-nous sur WhatsApp avec une photo dans les 7 jours suivant la livraison. Vous nous renvoyez le set par La Poste, les frais de retour sont à notre charge, et nous vous remboursons ou le remplaçons.

Merci de bien vérifier la forme, la longueur et la couleur avant de commander. Pour toute question, écrivez-nous sur WhatsApp avant de commander.

Livraison

Envoi par La Poste partout à Maurice (Rs 100) ou retrait gratuit à Pamplemousses. Paiement par Juice après confirmation sur WhatsApp.

Returns and exchanges

Every Pink Tips set is handmade. For hygiene reasons, we only accept returns for defective products. We do not accept exchanges.

Defective product

If your set arrives damaged, broken or not as described, message us on WhatsApp with a photo within 7 days of delivery. Send the set back by La Poste, we pay the return shipping, and we refund or replace it.

Please check the shape, length and colour carefully before ordering. If you have any question, message us on WhatsApp before you order.

Delivery

Shipped by La Poste all over Mauritius (Rs 100) or free pick-up in Pamplemousses. Payment by Juice after confirmation on WhatsApp.
